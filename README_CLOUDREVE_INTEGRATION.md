# 游戏回放文件Cloudreve网盘集成

## 项目概述

本项目为游戏系统添加了回放文件的远程备份和管理功能，通过集成Cloudreve网盘系统，实现了以下核心需求：

1. **远端Cloudreve的配置管理** - 支持服务器地址、用户认证等配置
2. **录像回放管理界面** - 管理员可以对录像进行归档并备份至远端Cloudreve网盘
3. **本地文件管理** - 移除本地服务器上备份完成的录像
4. **远程文件下载** - 从远端Cloudreve网盘下载特定录像

## 快速开始

### 1. 配置Cloudreve
```php
// 编辑 gamedata/cloudreve.config.php
$cloudreve_config = array(
    'host' => 'https://your-cloudreve-server.com',
    'username' => 'your_username',
    'password' => 'your_password',
    'enabled' => true,
    // ... 其他配置
);
```

### 2. 访问管理界面
1. 以管理员身份登录游戏
2. 进入管理员界面
3. 点击"回放文件管理"

### 3. 测试连接
1. 点击"配置设置"
2. 填写Cloudreve服务器信息
3. 点击"测试连接"验证配置

### 4. 开始使用
- 查看本地和远程文件列表
- 备份重要回放文件
- 管理存储空间
