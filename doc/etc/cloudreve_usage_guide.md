# Cloudreve回放文件管理系统使用指南

## 概述

本系统为游戏回放文件提供了与Cloudreve网盘的集成功能，支持自动备份、远程存储和文件管理。

## 功能特性

### 1. 配置管理
- 支持Cloudreve服务器连接配置
- 用户认证信息管理
- 存储路径自定义
- 自动删除策略设置

### 2. 文件管理
- 本地回放文件列表查看
- 远程回放文件列表查看
- 文件备份状态显示
- 批量操作支持

### 3. 操作功能
- 单个文件备份到Cloudreve
- 批量文件备份
- 从Cloudreve下载文件
- 删除本地或远程文件

## 安装配置

### 1. 前置条件
- PHP 7.0+ 环境
- cURL 扩展支持
- 有效的Cloudreve服务器访问权限

### 2. 配置步骤

#### 步骤1：访问管理界面
1. 以管理员身份登录游戏
2. 进入管理员界面
3. 点击"回放文件管理"

#### 步骤2：配置Cloudreve连接
1. 点击"配置设置"按钮
2. 填写以下信息：
   - **服务器地址**：Cloudreve服务器URL（如：https://your-cloudreve.com）
   - **用户名**：Cloudreve账号用户名
   - **密码**：Cloudreve账号密码
   - **存储路径**：回放文件在Cloudreve中的存储目录（默认：/replays）
   - **自动删除本地文件**：设置备份后自动删除本地文件的天数（0表示不删除）
   - **启用备份**：勾选以启用Cloudreve备份功能

#### 步骤3：测试连接
1. 配置完成后点击"保存配置"
2. 点击"测试连接"验证配置是否正确
3. 如果连接成功，系统会显示成功消息

## 使用方法

### 1. 查看文件列表

#### 本地文件
- 系统会自动扫描 `gamedata/replays/` 目录
- 显示文件名、大小、修改时间
- 标识文件是否已备份到远程

#### 远程文件
- 显示Cloudreve中的回放文件
- 显示文件大小和修改时间
- 标识文件是否存在于本地

### 2. 备份操作

#### 单个文件备份
1. 在本地文件列表中找到要备份的文件
2. 点击文件右侧的"备份"按钮
3. 系统会将文件上传到Cloudreve

#### 批量备份
1. 勾选要备份的多个文件
2. 点击"批量备份"按钮
3. 确认操作后系统会依次备份所有选中文件

### 3. 下载操作

#### 从远程下载
1. 在远程文件列表中找到要下载的文件
2. 点击"下载"按钮
3. 文件会被下载到本地 `gamedata/replays/` 目录

### 4. 删除操作

#### 删除本地文件
1. 在本地文件列表中选择要删除的文件
2. 点击"删除本地"按钮
3. 确认操作后文件会从本地删除

#### 删除远程文件
1. 在远程文件列表中选择要删除的文件
2. 点击"删除远程"按钮
3. 确认操作后文件会从Cloudreve删除

#### 批量删除本地文件
1. 勾选要删除的多个本地文件
2. 点击"批量删除本地"按钮
3. 确认操作后所有选中文件会被删除

## 安全注意事项

### 1. 权限管理
- 只有管理员权限6级及以上用户可以访问
- 所有操作都会记录在管理员日志中

### 2. 数据安全
- 建议定期备份重要回放文件
- 删除操作不可恢复，请谨慎操作
- 配置文件中的密码会以明文存储，请确保服务器安全

### 3. 网络安全
- 建议使用HTTPS连接Cloudreve服务器
- 定期更换Cloudreve账号密码

## 故障排除

### 1. 连接失败
**问题**：测试连接时显示失败
**解决方案**：
- 检查服务器地址是否正确
- 验证用户名和密码
- 确认Cloudreve服务器可访问
- 检查网络连接

### 2. 上传失败
**问题**：文件备份时失败
**解决方案**：
- 检查文件大小是否超过限制
- 确认Cloudreve存储空间充足
- 验证文件权限
- 检查网络稳定性

### 3. 下载失败
**问题**：从远程下载文件失败
**解决方案**：
- 确认本地目录可写
- 检查磁盘空间
- 验证文件是否存在于远程
- 检查网络连接

### 4. 权限错误
**问题**：无法访问管理界面
**解决方案**：
- 确认用户具有管理员权限
- 检查权限级别是否达到6级
- 联系系统管理员

## 配置文件说明

### 配置文件位置
`gamedata/cloudreve.config.php`

### 主要配置项
```php
$cloudreve_config = array(
    'host' => 'https://your-cloudreve-server.com',  // 服务器地址
    'username' => 'admin',                          // 用户名
    'password' => 'your_password',                  // 密码
    'api_version' => 'v4',                          // API版本
    'timeout' => 30,                                // 连接超时
    'replay_storage_path' => '/replays',            // 存储路径
    'enabled' => false,                             // 是否启用
    'auto_delete_local_days' => 30,                 // 自动删除天数
    'max_retry' => 3,                               // 最大重试次数
    'compress_upload' => true,                      // 是否压缩上传
    'allowed_extensions' => array('dat', 'rep', 'js'), // 允许的扩展名
    'max_file_size' => 100,                         // 最大文件大小(MB)
    'batch_limit' => 50                             // 批量操作限制
);
```
