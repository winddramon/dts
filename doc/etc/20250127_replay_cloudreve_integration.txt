回放文件Cloudreve网盘集成实现记录
时间戳: 2025-01-27

## 实现概述
为游戏系统添加了回放文件的远程备份和管理功能，集成Cloudreve网盘系统，实现以下功能：
1. 远端Cloudreve的配置管理
2. 录像回放管理界面，支持归档并备份至远端Cloudreve网盘
3. 移除本地服务器上备份完成的录像
4. 从远端Cloudreve网盘下载特定录像

## 新增文件

### 1. gamedata/cloudreve.config.php
- Cloudreve网盘配置文件
- 包含服务器地址、用户名、密码等必备信息
- 支持启用/禁用、自动删除本地文件等配置选项

### 2. include/cloudreve.func.php
- Cloudreve API客户端类实现
- 支持用户认证、令牌刷新
- 实现文件上传、下载、列表、删除等操作
- 提供回放文件管理的辅助函数

### 3. include/admin/replaymng.php
- 管理员回放文件管理界面逻辑
- 支持单个和批量操作
- 包含备份、下载、删除等功能
- 配置管理和连接测试

### 4. templates/default/admin_replaymng.htm
- 回放管理界面的HTML模板
- 响应式设计，支持文件列表展示
- 包含本地和远程文件对比显示
- 提供批量操作和配置管理界面

## 修改文件

### 1. admin.php
- 在$admin_cmd_list数组中添加'replaymng' => 6
- 权限级别设置为6，允许管理员6级及以上访问

### 2. include/admin/admin.lang.php
- 添加回放管理相关的语言定义
- 'replaymng' => '回放文件管理'
- 'replaymng_comment' => '管理本地和远程回放文件，支持备份到Cloudreve网盘'

### 3. templates/default/admin_menu.htm
- 在管理员菜单中添加回放管理选项
- 按钮样式与现有菜单保持一致

## 功能特性

### 配置管理
- 支持Cloudreve服务器地址、用户名、密码配置
- 可设置远程存储路径
- 支持自动删除本地文件的天数设置
- 提供连接测试功能

### 文件管理
- 显示本地和远程文件列表
- 文件大小、修改时间等详细信息
- 备份状态标识（已备份/未备份）
- 支持单个文件操作和批量操作

### 操作功能
- 备份本地文件到Cloudreve
- 从Cloudreve下载文件到本地
- 删除本地或远程文件
- 批量备份和批量删除

### 安全特性
- 基于现有管理员权限系统
- 操作前确认提示
- 详细的操作日志记录
- 错误处理和用户反馈

## API集成

### Cloudreve API v4
- 使用JWT令牌认证
- 支持令牌自动刷新
- 文件上传使用分段上传策略
- 遵循Cloudreve File URI规范

### 错误处理
- 网络连接超时处理
- API错误码解析
- 用户友好的错误信息显示

## 使用说明

### 配置步骤
1. 访问管理员界面 -> 回放文件管理
2. 点击"配置设置"按钮
3. 填写Cloudreve服务器信息
4. 启用备份功能
5. 点击"测试连接"验证配置

### 日常操作
1. 查看本地和远程文件列表
2. 选择需要备份的文件进行备份
3. 下载远程文件到本地
4. 删除不需要的本地或远程文件
5. 使用批量操作提高效率

## 技术实现

### 认证流程
1. 使用用户名密码登录获取访问令牌
2. 令牌过期前自动刷新
3. 所有API请求携带Bearer令牌

### 文件上传流程
1. 获取上传策略和凭证
2. 使用CURLFile进行文件上传
3. 支持大文件上传

### 文件下载流程
1. 获取下载URL
2. 使用CURL下载到本地
3. 验证下载完整性

## 部署注意事项

### 权限要求
- 管理员权限级别6及以上
- gamedata目录需要写权限
- 需要cURL扩展支持

### 安全考虑
- 配置文件中密码为明文存储，需确保服务器安全
- 建议使用HTTPS连接Cloudreve
- 定期更换访问密码

### 性能优化
- 大文件上传可能需要调整PHP超时设置
- 批量操作建议分批进行
- 网络不稳定时可调整重试次数
